## 使用约定

| 你要做的事 | 怎么用本索引 |
| --- | --- |
| 按关键词找章节 | 查下表 `标签` 列，或直接 `grep -rn "<关键词>" docs/` |
| 精确引用某一节 | 章节号即锚点，如 `6.2.2.1`，GitHub 上可直接跳转 |
| 判断是否适用你的系统 | 每章 frontmatter 的 `rdkos_scope`，全库统一为 `3.0.0 ~ 3.5.0`，跨版本差异在正文显式标注 |
| 判断内容可信度 | `来源数` 列 = 该章 `> 来源：` 标注条数，可回溯到官方页或社区帖 |
| 程序化检索 | 读 `index.json`，字段：`id / volume / chapter / title / path / tags / summary / sections` |

1. **先定位版本**：答案依赖 RDKOS 版本。遇到 Python 推理相关问题时，先确认是 3.5.0+（`hbm_runtime`）还是 ≤3.4.1（`pyeasy_dnn`）。

4. **引用时带章节号**：例如「见 7.2 报错速查表」，比只给标题更可定位。
